# Casos Insólitos RPG — Foundry VTT

Sistema para jogar **Casos Insólitos — RPG de investigação paranormal**.

O sistema completo pode ser encontrado aqui:
https://casosinsolitos.com.br

## Versão

1.0.3 — compatível com Foundry VTT 13 e 14.

## Principais recursos

- Ficha de Investigador em abas.
- Inventário com equipamentos e armas como Items.
- Equipamentos com quantidade, carregado e evidência.
- Evidências destacadas visualmente no inventário.
- Armas com tipo, periculosidade e rolagem de dano.
- Condições contextualizadas junto aos recursos correspondentes.
- Morrendo e Insanidade Temporária automáticos ao chegar a 0 PV/PdS.
- Debilitado aplicado automaticamente ao sair de Morrendo, com aviso no Chat.
- Penalidade de -2 em Testes durante Insanidade Temporária.
- Cartas de Chat para testes, dano, insanidade, frenesi e condições.
- Exemplos para Especialização, Impulsos Investigativos e Âncora Emocional.
- Link de Regras abrindo o site oficial em nova aba.
